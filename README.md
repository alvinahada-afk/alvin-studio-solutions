# Alvin Studio Solutions

Create a premium modern SaaS-style website for Alvin Studio, a digital solutions studio for cafes, restaurants, UMKM, and retail businesses.

Main headline:
"Digital Solutions untuk Bisnis yang Ingin Berkembang"

Subtitle:
"Website profesional, POS, QR Ordering, dan sistem custom untuk membantu bisnis berjalan lebih efektif."

Create a responsive homepage with these sections:

Hero + CTA "Konsultasi Gratis" and "Lihat Project"

Problems: manual orders, messy transaction data, no professional website, difficult business monitoring

Solutions: Website Business, POS & QR Ordering, Custom System

Featured product: Cafe Flow POS with dashboard mockup and features: POS, QR Menu, Orders, Inventory, Reports

Portfolio: Cafe Flow POS + Business Website

How it works: Consultation → Scope → Development → Review → Handover

Pricing: Website from Rp600K, Company Profile from Rp800K, Business Website from Rp1.2JT, POS/Custom = Custom

Final CTA + Footer

Design: premium SaaS, clean, professional, navy/white/blue, Inter or Plus Jakarta Sans, rounded cards, subtle shadows, minimal animations. Inspired by Stripe/Moka/Mekari.

Make it look like a real technology company with a real product, NOT a generic freelance portfolio.

No login, database, payment system, blog, or unnecessary features. Prioritize visual quality, responsive mobile design, SEO basics, and clean reusable components.
